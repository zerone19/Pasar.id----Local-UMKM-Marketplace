MVP PASAR.ID

Minimum Viable Product untuk Marketplace UMKM Lokal

## 1. Tujuan MVP
Membuktikan alur inti: seller dapat memiliki toko dan menjual produk, sementara buyer dapat menemukan produk, checkout, dan membuat pesanan.

## 2. MVP Buyer — P0
Register, login, browse product, search, category, product detail, store detail, cart, checkout, address, create order, order history, profile.

## 3. MVP Seller — P0
Register seller, verifikasi seller, create/edit store, product CRUD, product image, stock management, order list, update order status, basic revenue.

## 4. MVP Admin — P0
Admin login, dashboard, user management, seller management, seller verification, store management, category management, product moderation, order monitoring.

## 5. MVP Payment
Cash on Delivery dan Manual Transfer. Payment gateway ditunda sampai core order flow stabil.

## 6. MVP Shipping
Pickup dan local delivery. Integrasi ekspedisi nasional ditunda.

## 7. Fitur yang Ditunda
Live chat, AI recommendation, flash sale, voucher kompleks, affiliate, loyalty point, shipping API kompleks, multiple payment gateway, advanced analytics, mobile app penuh, dan microservices.

## 8. Sprint MVP
Sprint 1: Infrastructure & Docker.

Sprint 2: Authentication & roles.

Sprint 3: Marketplace, store, product, category, search.

Sprint 4: Cart, address, checkout, order.

Sprint 5: Seller dashboard.

Sprint 6: Admin dashboard.

Sprint 7: Testing, security, deployment.

## 9. Definition of Done
Buyer bisa membeli produk; seller bisa mengelola toko/produk/order; admin bisa mengontrol marketplace; API siap digunakan client lain; sistem berjalan melalui Docker; dan alur order end-to-end berhasil diuji.
